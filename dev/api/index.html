API Reference

Result type

KrylovComplexity.KCResult — Type
KCResult{T<:AbstractFloat}

Container returned by simulate. Holds all outputs from a single Krylov complexity run.

Fields

  • b : Lanczos coefficients at working precision T
  • t : time grid (Float64)
  • K : Krylov complexity K(t) (Float64)
  • S : Krylov entropy S(t) (Float64)
  • Kdim : Krylov dimension (>0 = converged, -1 = max_iter reached)
  • reortho_count : total number of reorthogonalization passes performed
  • wall_time : elapsed wall time in seconds

Building the system

KrylovComplexity.build_system — Function
build_system(cfg) -> (H, O)

Build the Hamiltonian H and initial operator O from a configuration dict. Required keys: "model" and "N". Optional key "precision_build" sets the floating-point type used for construction (default :f64).

The returned O is normalised so that its Frobenius norm equals 1. See the model-specific *_hamiltonian / *_operator functions for model-specific parameters.

Lanczos algorithm

KrylovComplexity.lanczos — Function
lanczos(H, O; precision, reortho, remove_degeneracies, ...) -> (b, Kdim, reortho_count)

Compute the Lanczos b-coefficients for the Liouvillian superoperator L = [H, ·] acting on the operator O.

The algorithm builds the Liouvillian eigenbasis (CER) from H and O, then runs vectorial Lanczos in that basis at the requested working precision.

Arguments

  • H, O : sparse Hermitian matrices (any precision)
  • precision : working type – :f64, :double, :bigfloat, or integer bits
  • reortho : :none, :fro, :dro, :pro, :dpro
  • remove_degeneracies : collapse degenerate frequency blocks (default true)
  • max_iter : max Lanczos steps (default K_eff + 10)
  • eps_factor : convergence tolerance = eps_factor * sqrt(eps(T))
  • tol_factor : degeneracy collapse tolerance
  • eps_reortho_factor : PRO trigger = factor * sqrt(eps(T)) (default factor = 1)

Returns (b, Kdim, reortho_count).

Krylov complexity

KrylovComplexity.krylov_complexity_entropy — Function
krylov_complexity_entropy(b; time_max, dt_factor, n_out, tol, max_halvings) -> (t, K, S)

Compute Krylov complexity K(t) and Krylov entropy S(t) from the Lanczos coefficients b by solving the chain Schrodinger equation with RK4.

The initial time step is dt = dt_factor / maximum(b). If the RK4 solution does not satisfy the norm-conservation tolerance tol, the step is halved up to max_halvings times.

Returns three Vector{Float64} of length n_out: the time grid t, complexity K, and entropy S.

High-level wrapper

KrylovComplexity.simulate — Function
simulate(cfg; kwargs...) -> KCResult

Run the full pipeline (build system, Lanczos, complexity) from a YAML file path or a Dict. Keyword arguments override config file values.

Recognised keys (beyond model-specific ones):

  • precision : Lanczos working precision (:f64, :double, integer bits)
  • reortho : reorthogonalization method (:none, :fro, :dro, :pro, :dpro)
  • remove_degeneracies: collapse degenerate Liouvillian blocks (default true)
  • eps_reortho_factor : PRO trigger threshold factor (default: 1.0 * sqrt(eps(T)))
  • eps_factor : convergence threshold factor
  • tol_factor : degeneracy tolerance factor
  • max_iter : maximum Lanczos iterations
  • time_max : integration time (default 1000.0)
  • dt_factor : initial RK4 step = dt_factor / max(b) (default 0.1)
  • kc_out_resolution : number of output time points (default 2000)
  • output_dir : directory for output files (default "results/")
  • save : save full KCResult to output_dir/result.jld2
  • save_b : save b only to output_dir/b.jld2 (ignored if save is true)
