KrylovComplexity.jl

A Julia package for computing Krylov complexity and Krylov entropy of various quantum systems.

Given a configuration, the package generates the Hamiltonian $H$ and an initial operator $O$ of the system. Then, it computes the Lanczos $b$-coefficients of the Liouvillian superoperator $\mathcal{L} = [H, \cdot]$, from which it derives the Krylov complexity $C_K(t)$ and Krylov entropy $S_K(t)$ [Parker et al., 2019].

Currently, the following systems are supported: Ising, XXZ, XYZ, cSYK, GOE and GUE matrices.

The algorithm uses a constraint eigenspace representation to remove degenerate eigenvalues of the Liouvillian operator accounting for the projection of the initial operator (implemented based on [Eckseler et al., 2025]).

Quick start

using KrylovComplexity

H, O = build_system(Dict("model" => "ising", "N" => 6,
                          "hx" => 1.05, "hz" => 0.5,
                          "precision_build" => 1024))

b, Kdim, reortho_count = lanczos(H, O; precision=:double, reortho=:pro)

t, K, S = krylov_complexity_entropy(b; time_max=1000.0)

Or drive everything from a YAML config:

result = simulate("examples/ising.yaml")

Supported models

KeyModel
isingTransverse-field Ising chain
xyzXYZ spin chain
xxzXXZ chain with U(1) + ℤ₂ symmetry reduction
goeGOE random matrix
gueGUE random matrix
csykComplex SYK (all-to-all random quartic fermions)

See the README for full model equations, parameter tables, and precision/reorthogonalization options.
